# 单图星点识别测试（Barnard 2025W35 · D2）

> 时间：2026-11-15 05:00 CET
> 问题：一张 SPHEREx 图上能不能识别“所有的星”？
> 数据：C 8798 已 ingest 的 Barnard 单期 NPZ
> `dr1_2025W35_2A_0221_1_D2_269.4462_4.7673_0.200.npz`
> 真值：B 8801 真实 Gaia DR3 7 场缓存（17,679 源，category `tap`）
> 方法：C `/api/v1/sources` 检测源 vs Gaia 传播到 MJD 60916.656 的位置；3.075″/6.15″ 匹配；另用 B `/api/v1/catalog/match` 批量比对 47 个检测源。

---

## 0. 结论

**不能识别“所有的星”。**

这张图里：

- C 检测到 **47 个源**；
- 同一 0.13° 半径内 Gaia 有 **2,583 个星**；
- 检测率约 **1.8%**；
- 只有**亮星**较完整：G<12 约 80%，G 12–14 约 65%，G 14–16 约 13%，G 16–18 约 1%；
- 一个 6.15″ 像素里常有多颗 Gaia 星：47 个检测源在 6.15″ 内对应 71 个 Gaia 源，说明**混合严重**；
- 对 47 个检测源做 Gaia 匹配：31 个单候选、6 个 ambiguous、10 个无匹配（3″ 半径）。

所以当前能力是：

> **在一张图上检测“较亮的点源”，不是识别“所有的星”，更不是给每个源一个恒星身份。**

---

## 1. 检测数量

| 项 | 数值 |
|---|---:|
| C 检测源 | **47** |
| Gaia（0.13° 锥，传播到观测 MJD） | **2,583** |
| 检测/Gaia | **1.8%** |
| C 源 S/N 范围 | 24.4 – 161.7 |
| C 源质量 | 含 `SATURATED` 等标记；不全是恒星 |

> 0.13° 锥略大于 0.2° 图像，但用于量级比较；不是严格足迹求交。

## 2. 位置匹配

| 匹配半径 | Gaia 被匹配 | C 源无 Gaia 对应 |
|---|---:|---:|
| 3.075″（0.5 px） | 43 / 2,583 | 10 / 47 |
| 6.15″（1 px） | 71 / 2,583 | 3 / 47 |
| 12.3″（2 px） | 134 / 2,583 | 1 / 47 |

6.15″ 内 47 个检测源对应 71 个 Gaia 源，说明：

- 6.15″/px 下**多颗星落进一个检测源**；
- 一个“点”可能是混合源，不能只用位置判成一颗星；
- 无 Gaia 对应的 C 源可能是伪源、极暗星、混合源或 Gaia 未收录。

## 3. 按 Gaia G 波段的完整度

| Gaia G | Gaia 数 | 6.15″ 内匹配 | 完整度 |
|---|---:|---:|---:|
| <12 | 5 | 4 | **80%** |
| 12–14 | 34 | 22 | **65%** |
| 14–16 | 131 | 17 | **13%** |
| 16–18 | 580 | 7 | **1.2%** |
| 18–20 | 1,833 | 21 | **1.1%** |

结论：

- 只对 **G≲14** 的亮星有较高完整度；
- G>16 基本无法从这张图可靠检测；
- 这张图的检测上限不是“所有星”，而是“亮源 + 部分混合源”。

## 4. 身份匹配（不是检测）

对 47 个 C 源调用 B `/api/v1/catalog/match`（3″、Gaia、MJD 60916.656）：

| 状态 | 数量 |
|---|---:|
| `single_candidate` | **31** |
| `ambiguous` | **6** |
| `no_match` | **10** |

含义：

- 31 个可给单候选（仍需 RUWE/PM/质量门，不等于确认）；
- 6 个在 3″ 内有多个 Gaia 源 → ambiguous；
- 10 个无匹配：可能是伪源、极暗星、混合源，或 Gaia 未覆盖；**不能写成“新恒星”**。

## 5. 为什么不能“全部识别”

1. **深度有限**：SPHEREx 单期 5σ 深度不足以探到 Gaia G>16–18 的绝大多数星。
2. **像素太大**：6.15″/px，星与星混合；一个检测源可能是多颗星。
3. **检测阈值/质量过滤**：C 用 `detect_sources`（6σ、质量标记、最大源数），不是“全源目录”。
4. **没有全源身份分类**：D 只对选中源做 Gaia 比对；不会把 47 个源自动分成恒星/星系/伪源。
5. **单张图没有时间信息**：不能判运动/变光；只能给单期检测。

## 6. 当前能做什么

- 在一张图上找出**较亮的点源**（本例 47 个）；
- 给出每个源的 RA/Dec、S/N、flux、质量标记；
- 对选中的源做 Gaia 已知/ambiguous/未匹配检查；
- 对亮源（G≲14）有较高检测完整度。

## 7. 不能做什么

- 不能识别图上**所有** Gaia 星；
- 不能保证每个检测源都是恒星；
- 不能凭单张图确认行星/新天体；
- 不能把 `no_match` 说成“新恒星”。

## 8. 证据/复现

```bash
# 1) C 源
curl -s 'http://127.0.0.1:8798/api/v1/sources?ra=269.4462&dec=4.7673&fov=0.25&epoch=2025W35_2A_0221_1&limit=5000'

# 2) Gaia 真值（完整 7 场缓存，8801）
curl -s 'http://127.0.0.1:8801/api/v1/catalog/cone?ra=269.4462&dec=4.7673&radius_deg=0.13&epoch=60916.656&catalog=gaia&limit=2000&offset=0'

# 3) 批量身份候选
curl -s -X POST 'http://127.0.0.1:8801/api/v1/catalog/match' \
  -H 'Content-Type: application/json' \
  -d '{"detections":[{"ra":269.45476104,"dec":4.8516613,"mjd":60916.656061887,"sigma_arcsec":0.5}],"catalogs":["gaia"],"radius_arcsec":3.0,"epoch":60916.656}'
```

**最终判定：当前是“单图亮源检测 + 选中源 Gaia 比对”，不是“单图全星识别”。**
