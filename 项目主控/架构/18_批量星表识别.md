# 批量星表识别计划（A/C 源表）

> 目标：把“点一个源才识别”升级为“对 A/C 源表批量识别并显示三态”，让全量 Gaia 缓存真正进入产品链路。
> 前置：B 已是 17,679 源 / 7 场 / schema v3；单源 `/api/identify` 已可用。

---

## 0. 范围

做：

- app 新增批量识别 API；
- 复用 B `/api/v1/catalog/match` 批量接口；
- C 源列表增加“批量识别”按钮 + known/ambiguous/no_match 徽标；
- 47 个 Barnard C 源端到端验证；
- 结果不写 DB、不写“新天体”。

不做：

- 不做 A 源表的全新表格 UI（先保留点选）；
- 不做 2MASS/WISE/SIMBAD 新目录（后续）；
- 不做自动 ingest（TAP 当前超时）。

---

## 1. API

```http
POST /api/identify/batch
```

```json
{
  "sources": [
    {"source_id": "c-001", "ra": 269.4, "dec": 4.7, "mjd": 60916.6, "sigma_arcsec": 0.5}
  ],
  "catalogs": ["gaia"],
  "radius_arcsec": 3.0
}
```

返回：

```json
{
  "schema_version": "1.0",
  "n": 47,
  "counts": {
    "known_star": 31,
    "ambiguous": 6,
    "insufficient_data": 0,
    "uncatalogued_candidate": 0,
    "catalog_unavailable": 0,
    "no_match": 10
  },
  "results": [
    {
      "source_id": "c-001",
      "status": "known_star",
      "label_zh": "Gaia DR3 已知",
      "catalog_id": "...",
      "separation_arcsec": 0.3,
      "reason": "SINGLE_CATALOG_MATCH",
      "quality": [],
      "caveats": []
    }
  ],
  "catalog_status": "ok",
  "discovery_claim": false
}
```

规则：

- 最多 200 源；
- B 批量返回 `single/ambiguous/no_match`，app 统一映射；
- `no_match` → `uncatalogued_candidate`（不叫未知星体）；
- B 不可用 → 全部 `catalog_unavailable`，HTTP 200；
- 单源 `separation > 6.15″` 仍走 insufficient；
- 不写 DB。

---

## 2. app 客户端

`CatalogClient.match_batch(...)`：

- POST B `/api/v1/catalog/match`，一次传所有 detections；
- 保留 B 的 `catalog_status`；
- 把每个 match 转成 app 的 `catalog_layer.identify` 输入。

---

## 3. UI

C 源列表：

- 增加“批量识别 C 源”按钮；
- 识别中显示进度/禁用；
- 完成后显示：
  ```text
  known 31 / ambiguous 6 / no_match 10
  ```
- 每行加 badge：
  - known → 青绿
  - ambiguous → 琥珀
  - no_match → 灰
  - catalog_unavailable → 红
- 点击行仍走单源 `/api/identify`；
- 失败不覆盖旧列表，显示可读错误。

---

## 4. 测试

- fake B batch：single + ambiguous + no_match 映射；
- B 不可用：全部 catalog_unavailable；
- 6.15″ 偏移仍 insufficient；
- 200 源上限 400；
- UI 静态：按钮、counts、badge、失败文案；
- 现有 259 tests 不回归。

---

## 5. 验收

- Barnard 47 C 源：
  - counts 31 known / 6 ambiguous / 10 no_match；
  - UI badge 与 API 一致；
  - 无 JS error；
- T1 45/0/1、T6 0；
- 不出现“新天体/新恒星”正结论。

---

## 6. 风险

| 风险 | 缓解 |
|---|---|
| 批量 B 请求太大 | 上限 200；分页可后续 |
| C 源坐标/误差缺失 | 缺字段跳过并标记 |
| B 不可用 | 200 + 全部 catalog_unavailable |
| ambiguous 被误显示 known | 严格按 status 映射 |
| 自动写 DB | 不写；仅读 |
