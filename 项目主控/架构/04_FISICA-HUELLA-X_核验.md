## 0. 先给结论

### 可以用的部分

- **球面几何**：haversine 角距公式正确。
- **运动学**：`v = sep / Δt`、`σ_sep = √(σ_A²+σ_B²)`、`significance = sep/σ_sep` 在“误差独立、同一参考架、同一历元定义”的前提下正确。
- **黑体**：Planck 公式、SI 常数、Wien 位移定律 `λ_peak = 2898/T` 正确。
- **加权拟合**：`k = Σwfm/Σwm²`、`χ²_red = Σ((f-km)/σ)²/(N-1)` 在“只有一个尺度参数、σ 已知且独立”的前提下正确。
- **工程思路**：`IMAGE − ZODI` 去黄道光、孔径测光减背景环、用 `VARIANCE` 传播误差、按 MJD 查 JPL/MPC，这些是合理做法。

### 不能直接用的部分

1. **0.2° 与 233×234 px 的场大小自相矛盾**，并导致“72 h = 3° = 六倍视场”算错。
2. **0.5 h 最小间隔的理由不成立**：主带天体 75″/h 在 0.5 h 已走 37.5″≈6.1 px。
3. **150″/h 不是物理上限**，只是“2×主带”的设计上限；近地天体可以更快。
4. **FWHM=2 px≈12″ 不是固定物理值**；官方 PSF 与 6.2″ 像素同量级，应该从 EPSF 测，2 px 只能当上限。
5. **`<2σ = estacionaria` 语义过强**：不显著只能给“未探测到运动”的上限，不能证明静止。
6. **选期评分把小时和天直接相加**，量纲不一致；实现时会被“天”支配。
7. **500 AU、albedo 0.4 → 12.4 K 数值不自洽**：正确约 10.95 K；12.45 K 是忽略 albedo 的结果。
8. **“DR1 同一 detector 最多两次访问 / 只有两个历元”不是普遍事实**，与当前 4/8/8/1/3 历元数据冲突。
9. **“每个数字都在代码里且有测试”无法核实**；旧 `m1..m6` 目录不在本仓库，且很多阈值明显是经验值。
10. **T=50–3000 K 的 Planck 拟合范围过宽**；50 K 的峰值在 58 µm，0.75–5 µm 只有 Rayleigh–Jeans 尾部，温度基本不可约束。
11. **Planck 公式未说明 λ 单位**；若 λ 用 µm、常数用 SI，`hc/λkT` 会错 10⁶ 倍。
12. **模板分类/χ² 阈值没有引用与注入-回收验证**；只能算启发式，不是物理定律。

| 253.00″ / 1.36″ | **186.0σ** | ✅ 算术，不代表系统误差 |
| 60″ / 0.7″ | **85.7** | ✅（文中“85 倍”） |
| 1.4″ / 6.15″ | **0.228 px** | ✅（文中≈0.2 px） |
| 2 px × 6.15″ | **12.3″** | ✅ 算术，但 FWHM 假设另说 |
| 500 AU、A=0.4 的平衡温度 | `[S0(1-A)/(4σd²)]^1/4`，S0=1361 W/m²，d=500 AU → **10.95 K**；`λ_peak=2898/T` → **264.5 µm** | ❌ 文中 12.4 K/233 µm |

**结论**：`12.4 K / 233 µm` 这一对数字内部一致（是 A=0 的黑体），但和“albedo 0.4”不自洽；结论“峰值不在 SPHEREx 波段”仍然成立，但推导要改。

> 另外：热峰值不在 0.75–5 µm，**不等于**“完全不可探测”。500 AU 行星在近红外仍可有反射光；是否可探测取决于半径、albedo、相位和 SPHEREx 深度。文中“no detectable”只证明了热峰在外，没有做反射光/灵敏度计算。

## 3. 公式层：哪些是对的

### 3.1 球面角距

```
h = sin²(Δδ/2) + cosδ₁ cosδ₂ sin²(Δα/2)
sep = 2 asin(√h)
```

✅ 正确；对小角度数值稳定，且对 RA 环绕安全。条件：`Δα` 用弧度、同一参考架。

### 3.2 速度

```
Δt_h = (MJD_B − MJD_A) × 24
v = sep / Δt_h          [″/h]
```

✅ 正确；要求 `sep` 是同一时间段内的角距，且目标未出视场。

### 3.3 误差与显著性

```
σ_sep = √(σ_A² + σ_B²)
σ_v   = σ_sep / Δt_h
S/N   = sep / σ_sep
```

✅ 在“两次位置误差独立、无系统差”的前提下正确。
⚠️ 若两次位置共用参考星/同一 WCS 校准，误差相关，`σ_sep` 会被低估；186σ 不能当作真实精度证据。

### 3.4 Planck 与 Wien

```
B_λ(T) ∝ 1 / [λ⁵ (e^(hc/λkT) − 1)]
λ_peak = 2898 / T        [µm·K / K = µm]
```

✅ 公式与常数正确（h=6.62607015×10⁻³⁴ J·s，c=2.99792458×10⁸ m/s，k=1.380649×10⁻²³ J/K）。
⚠️ **λ 必须用米**；若用 µm，指数应写 `hc/(λ_µm×10⁻⁶ kT)`，否则错 10⁶ 倍。
⚠️ 50–3000 K 太宽；50 K 的峰值 58 µm，0.75–5 µm 只有 RJ 尾部，温度不可约束。

### 3.5 加权尺度拟合

```
w_i = 1/σ_i²
k   = Σ w_i f_i m_i / Σ w_i m_i²
χ²_red = Σ ((f_i − k m_i)/σ_i)² / (N − 1)
```

✅ 单参数尺度、σ 已知且独立时正确。
⚠️ `N−1` 只适用于一个自由参数；若同时拟合 T、尺度、模板混合，分母应为 `N−p`。
⚠️ `χ²_red≤3`、`k/σ_k≥3`、`global≥3σ` 是经验阈值，不是物理定律；需要注入-回收校准。

### 3.6 工程做法

- `IMAGE − ZODI`：✅ 概念正确；残差和单位需逐帧检查。
- 孔径测光 + 背景环 + `VARIANCE` 传播：✅ 标准做法；孔径/环半径要按 EPSF 定，不应写死。
- 按 MJD 查询 JPL/MPC：✅ 正确思路；超时/限流是工程问题。
- §11 “RA/Dec 不能重建 3D”✅ 对“仅 SPHEREx 图像”成立；但 Gaia 视差可以提供距离，原文“任何 3D 星图都是编造的”过于绝对，应限定为“本工具不用 Gaia 视差”。

## 5. 作为“依据”的推荐用法

### 5.1 可以作为

- **公式检查表**：haversine、速度、误差、显著性、Planck、Wien、加权拟合。
- **工程 checklist**：ZODI 减法、孔径/背景环、VARIANCE、JPL/MPC 按日期查询、边缘掩膜。
- **数量级直觉**：6.15″/px、0.4° 方框、主带 75″/h、500 AU 热峰在远红外。

### 5.2 不可以作为

- **验收依据**：文中阈值没有经过当前数据的注入-回收/假阳性校准，不能拿来判定 T1/科学结论。
- **物理定律**：0.5 h、72 h、150″/h、5σ、1 px、χ²≤3、T 范围都是**设计选择**，不是自然常数。
- **实现依据**：旧 `m1..m6` 目录不存在于当前仓库；当前 MoveScope 是多历元/BIC 管线，不是“两历元 + 模板”的旧管线。
- **“已验证”证据**：单场 2 点光谱、186σ、139 个检测都不能证明通用规则；旧代码/测试不可见。
- **可直接引用的文字**：原文件无许可证/作者信息；如果是第三方旧项目，复制文字/代码前必须确认授权。

### 5.3 对当前项目的建议

1. 把本文降级为 `legacy reference`，在 `REFERENCES.md`/内部文档中标注“旧 HUELLA X 说明，非当前实现，非验收依据”。
2. 只把 §3 的公式和 §3.5 的加权拟合迁入当前理论文档；阈值必须重新标定并写测试。
3. 当前 MoveScope 继续用 `系统/docs/01` 的 BIC/多历元定义；不要引入旧项目的“两历元 + 固定 0.5/72 h”规则。
4. 若要在提交材料中引用“500 AU 行星不可探测”，改为：热峰在远红外 + 反射光灵敏度计算（或明确只讨论热辐射），不要只凭 Wien 峰下结论。
