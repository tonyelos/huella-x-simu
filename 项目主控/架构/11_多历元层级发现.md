# 多历元层级发现：可能性与架构

> 问题：能不能用多个连续图片的“分层结果”，自动发现不同层级的星体？
> 结论：**技术上可行，但只能做到“候选发现 + 分级 + 证据排序”；不能自动确认所有层级，尤其不能自动确认未知行星。**

---

## 0. 一句话

```text
每个历元分层（L1 / masked / residual）
  → 跨历元关联（tracklet）
  → 运动/变光/持续性模型
  → 星表/历表比对
  → 分级候选（D0–D5）
  → 人工/后续确认
```

这是**时域层级发现**，不是“单图分类”。

---

## 1. 什么是“不同层级的星体”

建议分两层含义：

### A. 亮度/检测层级

- L1：亮源、高 S/N；
- masked：已检测/已知源；
- residual：亮源附近/低阈值残差；
- stack：多历元叠加后的暗源。

### B. 证据/发现层级（更实用）

| 级别 | 含义 | 自动化 |
|---|---|---|
| D0 | artifact / 伪源 | 高 |
| D1 | 已知星表源（Gaia/2MASS/WISE） | 高 |
| D2 | 已知源 + residual 伴星候选 | 中 |
| D3 | 未知移动候选（无星表/历表匹配） | 中 |
| D4 | 未知静止候选（无星表匹配） | 低-中 |
| D5 | 已确认（follow-up/轨道/光谱） | 不由本工具完成 |

> “发现层级”不是物理分类，而是**证据强度分级**。

---

## 2. 可行性分级

| 目标 | 可行性 | 原因 |
|---|---|---|
| 已知亮星自动标注 | **高** | Gaia/2MASS/WISE + 位置匹配 |
| 亮源附近的 residual 伴星候选 | **中** | 需要 EPSF 扣除；6.15″/px 混合 |
| 多历元移动候选 | **中** | 需 ≥3 期、轨迹关联；伪源多 |
| 变光候选 | **中** | 需同波段测光；不同波段不可直接比 |
| 未知静止源（星系/QSO/暗星） | **低-中** | 无星表时无法确认性质 |
| 未知行星确认 | **极低/不可** | 需轨道/后续观测 |
| 物理形态/质量/半径 | **低** | 单图/少历元模型退化 |

## 3. 多历元层级发现架构

### 3.1 每个历元：三层

```text
L1: detect_sources(6σ, ≤80)
masked: L1 位置 + 2px 掩膜/局部中值
residual: mask 后 5σ 复检（≤80）
```

已有 `/cascade` 页可看。

### 3.2 跨历元：tracklet 关联

```text
候选节点 = L1 + residual + (可选) stack
边 = 位置/时间/误差兼容
tracklet = 跨 ≥2 历元的节点链
```

轨迹模型：

- `stationary`：位置不变（<3σ）；
- `linear`：匀速直线（PM/小行星）；
- `accelerating/curved`：二次/轨道候选；
- `variable`：位置不变、流量变；
- `transient`：只出现部分历元；
- `residual-only`：只在亮源附近残差中出现。

### 3.3 分级

```text
D0: artifact（flags/PSF/不重复）
D1: known catalog（Gaia/2MASS/WISE/MPC）
D2: known + residual companion
D3: unknown moving candidate
D4: unknown stationary candidate
D5: confirmed (human/follow-up)
```

### 3.4 证据字段

```json
{
  "track_id": "...",
  "level": "D3",
  "nodes": [{"epoch": "...", "stage": "L1|residual", "ra": ..., "dec": ...}],
  "motion": "linear|curved|stationary|variable",
  "catalog_match": "known|ambiguous|unmatched",
  "confidence": 0.7,
  "caveats": ["residual near bright star", "only 2 epochs"],
  "discovery_claim": false
}
```

## 4. 为什么不能“全自动确认”

1. **6.15″/px 混合**：一个点可能是多颗星；residual 可能是 PSF 翼。
2. **历元太少**：2–8 期、6 个月间隔；轨道/加速度退化。
3. **不同波段**：流量不可直接比；变光/颜色要同波段。
4. **伪源**：ghost、streak、satellite、snowball、边缘。
5. **星表不完备**：无 Gaia ≠ 新星；极红/暗源缺失。
6. **未知行星**：需要轨道/后续观测，不能由单工具确认。
7. **选择偏差**：mask 亮源后 residual 只覆盖残余区域，不能统计“所有星”。

---

## 5. 最小可行实验（建议）

在 Barnard 4 期上：

1. 每期跑 `/cascade`，得到 L1/residual；
2. 把 L1 + residual 按 RA/Dec 关联成 tracklet；
3. 对 tracklet 拟合 stationary/linear；
4. 与 Gaia/2MASS/WISE 匹配；
5. 统计：
   - 已知星 track 数；
   - 未知 moving 候选；
   - residual-only track（伴星/伪源）；
   - 伪源比例；
6. 用 injection-recovery 注入假移动源，测回收率/假阳性；
7. 不把任何 track 自动叫“新天体”。

---

## 6. 可行性结论

### 能做

- 自动生成**分层候选目录**；
- 自动标注已知星；
- 自动找**移动/变光/残差候选**；
- 自动分级 D0–D4；
- 提供证据、置信度、证伪条件。

### 不能做

- 自动确认“新行星”；
- 自动给出所有天体的物理形态；
- 保证所有层级都完整；
- 用单图/少历元替代 follow-up。

### 推荐定位

> **多历元层级发现 = 候选发现/排序系统，不是自动发现确认系统。**

如果要做，下一步应是：

1. tracklet 关联；
2. D0–D4 分级；
3. injection-recovery 验收；
4. 人工/后续确认入口。
