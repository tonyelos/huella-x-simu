# 批量结果审计导出计划

> 目标：A/C 批量识别结果不只停留在 badge，还能导出可审计的 CSV/JSON。
> 本轮不新增星表目录，不改 B/DB/C；只把结果（含 Gaia 候选、RUWE、2MASS/WISE 列）导出。

---

## 0. 数据来源

A/C 批量结果已在：

- `state.aSourceBatch.byId`
- `state.anyfieldBatch.byId`

每个结果含：

```text
source_id, status, label_zh, catalog_id, release, separation_arcsec,
ruwe, n_candidates, reason, quality, caveats,
candidates[]（含 jmag/hmag/kmag/w1/w2）
```

A/C 源表提供 `epoch_id/frame/ra/dec/mjd`。

---

## 1. 导出格式

### CSV 列

```text
source_id,epoch_id,frame,ra,dec,mjd,status,label_zh,catalog_id,release,
separation_arcsec,ruwe,n_candidates,jmag,hmag,kmag,w1,w2,reason,quality,caveats
```

规则：

- `no_match` → status `uncatalogued_candidate`，label“未收录候选”；
- ambiguous 的 `catalog_id` 为空，`n_candidates>1`；
- J/H/K/W1/W2 缺失留空，不补 0；
- quality/caveats 用 `;` 连接；
- UTF-8 BOM，Excel 可读；
- 文件名 `movescope_A_batch_<target>_<UTC>.csv` / C 同理。

### JSON

同结构数组，便于程序审计。

## 2. UI

- A 表批量按钮旁加“导出 CSV”；
- C 列表批量按钮旁加“导出 CSV”；
- 未批量前隐藏/禁用；
- 导出计数与页面 counts 一致；
- 导出不改变表格/badge；
- 明确“导出是候选身份，不是发现声明”。

## 3. 测试

- 纯函数：CSV 转义（逗号/引号/换行）、缺失值空、ambiguous 空 catalog_id、J/W1 列；
- A/C 按钮静态；
- 未批量不导出；
- 导出后状态不变；
- 现有 268 tests 不回归。

## 5. 风险

| 风险 | 缓解 |
|---|---|
| CSV 公式注入 | 只导出数字/受控枚举；文本列加引号 |
| 大表卡顿 | 前端 Blob；不逐行 DOM |
| 缺失值被写成 0 | 空字符串 |
| ambiguous 被误给单 ID | catalog_id 留空 |
