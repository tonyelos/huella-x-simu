# 数据接收接口与自动缓存计划

> 目标：新增“从外部星表 API 接收 → 写 SQL → 分析层自动调用”的闭环。
> 范围：Gaia TAP（可扩展到 2MASS/WISE）/ B 星表 SQL / app 客户端。
> 不做：全量 Gaia、无界重试、无许可缓存、把 no_match 当新天体。

---

## 0. 数据流

```text
app /api/analyze 或 /api/identify
  → CatalogClient.match
      → B /api/v1/catalog/match
          → 场未缓存/partial
              → B /api/v1/catalog/ingest
                  → Gaia TAP cone
                  → SQL catalog_source/catalog_field
              → 重试 match
      → known/ambiguous/insufficient
```

---

## 1. B 接口

### POST `/api/v1/catalog/ingest`

```json
{
  "catalog": "gaia",
  "ra": 158.578,
  "dec": 9.595,
  "radius_deg": 0.25,
  "mag_limit": 20.0,
  "field_id": "auto-158.5780-9.5950-r0.25",
  "field_name": "auto field RA 158.578 Dec 9.595",
  "include_photometry": false,
  "replace_field": true
}
```

返回：

```json
{
  "schema_version": "1.0",
  "ok": true,
  "catalog": "gaia",
  "release": "gaia-dr3",
  "field_id": "...",
  "counts": {"n_sources": 1234, "n_new": 1234, "n_fields": 8},
  "provenance": "tap",
  "complete": true,
  "radius_deg": 0.25,
  "mag_limit": 20.0,
  "fetched_at": "...",
  "warnings": []
}
```

规则：

- 只允许 `catalog=gaia`（MVP）；
- `radius_deg` 0.05–1.0；`mag_limit` 12–20；
- TAP 失败/结果截断 → **502 `UPSTREAM_TAP_ERROR`**，不写部分数据；
- 成功才写 SQL；写入用事务；
- 已有 release 时**场级 upsert**，不删其它场；
- 同场重入：替换该场源与 field 元数据；不误删相邻场；
- 记录 `catalog_import_run` 与 `star_meta.last_import_at`；
- 响应带许可/引用/来源；
- 服务仍只监听 127.0.0.1；写入连接与读连接分离。

### SQL 写入

`StarCatalog` 新增 `upsert_field(...)`：

- 找/建 release；
- 按 `source_id` INSERT OR REPLACE；
- 替换 `catalog_field` 该 field_id；
- 更新 release `n_sources`；
- 保留其它 field；
- 不写 `catalog_match`。

## 2. app 自动调用

`CatalogClient`：

- 新增 `ingest(ra, dec, radius_deg=0.25, ...)`；
- `match()` 后若 `catalog_status` 为 `partial`/`unavailable` 且 reason 是 `no_cached_field`：
  - 若 `CATALOG_AUTO_INGEST=1`：
    * 调 B ingest；
    * 成功后重试 match 一次；
    * 失败仍返回原 `catalog_unavailable/partial`，不阻塞分析；
  - 默认关闭，避免每次分析触发网络；
  - T5/演示可显式开启。

环境变量：

```text
CATALOG_AUTO_INGEST=1
MOVESCOPE_CATALOG_INGEST_TIMEOUT=60
```

## 3. 测试

### B

- 合成源 + 临时 SQL：`upsert_field` 新场/重入/相邻场保留；
- HTTP `POST /api/v1/catalog/ingest`：
  - 200 并落库；
  - TAP 失败 502 且计数不变；
  - 非法 radius/mag 400；
  - 重复 ingest 幂等；
- 现有 118+ tests 不回归。

### app

- fake B server：match partial → ingest → match ok；
- auto ingest 关闭时不调用；
- ingest 失败仍返回 catalog_unavailable；
- 现有 250 tests 不回归。

### 验收

- 临时 SQL + B 8802，ingest 一个场，`catalog_status=ok`；
- app 指向 8802，`/api/identify` 从 insufficient 变成 known/ambiguous（视真实星表）；
- T1 45/0/1、T6 0 ERROR；
- 不写生产 DB、不提交大缓存。

## 5. 风险

| 风险 | 缓解 |
|---|---|
| TAP 慢/不稳定 | 超时、一次重试、502 不写 |
| 重复源 | `INSERT OR REPLACE`，source_id 唯一 |
| 覆盖相邻场 | 场级 upsert，不删整个 release |
| 网络在分析路径阻塞 | 默认关闭 auto；显式 env |
| 许可 | 响应/DB 带 Gaia CC BY-NC 等 |
| 缓存过大 | 半径≤1°，mag≤20；不提交 DB |
