> 目标：把当前“画布点选 A 源”升级为“A 源表批量星表识别”，与 C 源表对齐。
> 前置：app `/api/identify/batch` 已存在（最多 200 源）；B 为 17,679 源全量缓存。

## 1. A 源字段

A 源来自 `/api/analyze` 的 `sources`：

```json
{
  "epoch_id": "real-...-D2",
  "frame": 0,
  "x": 62.016, "y": 8.682,
  "ra": 269.454761, "dec": 4.851661,
  "flux": 128.3, "snr": 161.68,
  "quality": [], "sigma_x": 0.05, "sigma_y": 0.05
}
```

批量请求：

```text
source_id = "<epoch_id>:<x>:<y>"
mjd = epochs[frame].mjd
sigma_arcsec = max(0.3, hypot(sigma_x,sigma_y)*6.15)
```

- 215 源 → 2 批（200 + 15）；
- 计数合并；每行按 source_id 映射 badge。

▸ A 检测源（本次分析） 215 个 · 批量识别 A 源

- 仅分析完成且 sources 非空时显示；
