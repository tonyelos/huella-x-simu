# 跨历元轨迹发现 · 实施计划

> 目标：把 `/cascade` 的单历元分层（L1 / masked / residual）扩展成**跨历元 tracklet**，自动输出 D0–D4 候选层级。
> 边界：候选发现/分级，不是“自动确认新天体/新行星”。

---

## 1. 范围

### 做

1. 每历元 L1 + residual 节点；
2. 跨历元关联成 tracklet；
3. 轨迹模型：stationary / linear / curved / variable / transient；
4. 层级：
   - D0 artifact；
   - D1 known catalog（Gaia/2MASS/WISE）；
   - D2 known + residual companion（可选）；
   - D3 unknown moving；
   - D4 unknown stationary；
   - D5 confirmed（不在本工具）。
5. API `/api/tracks` + UI 轨迹层；
6. 合成注入 + Barnard 真实验证 + Ego。

### 不做

- 不做未知行星确认；
- 不做物理形态/质量/半径；
- 不把 residual 或 `no_match` 写成“新天体”；
- 不做跨 release 混测光；
- 不做全量全天索引。

---

## 2. 算法

### 2.1 输入

```text
每历元 cascade：
  L1: 6σ，≤80
  residual: 5σ，≤80，mask 2px
节点字段：
  epoch_id, mjd, stage, x, y, ra, dec, snr, flux, quality
```

### 2.2 关联

- 以时间排序，逐历元建节点；
- 位置门限：`max_sep_px`（默认 3 px ≈ 18.5″），可随 epoch 间隔放大；
- 简单贪心/最近邻 + 匈牙利匹配（MVP 贪心即可）；
- 允许 tracklet 缺 1 期（gap）；
- 同一源不能重复进两条 tracklet；
- residual 节点可继承最近 L1 的 `parent_id`。

### 2.3 轨迹模型

```text
stationary: 位置斜率 < 3σ
linear:     线性拟合 ΔBIC > 6，且速度显著
curved:     二次项显著（ΔBIC > 6，accel > 4σ）
variable:   位置 stationary，流量 χ² 显著
transient:  只出现部分历元
```

### 2.4 层级

| 级别 | 条件 |
|---|---|
| D0 | quality 命中 artifact/edge/饱和/不重复/PSF 异常 |
| D1 | Gaia/2MASS/WISE 单候选匹配，PM 一致 |
| D2 | D1 + residual 伴星节点（可选） |
| D3 | 无星表匹配 + linear/curved 移动 |
| D4 | 无星表匹配 + stationary/transient 静止 |
| D5 | 人工/后续确认（不自动） |

### 2.5 输出

```json
{
  "track_id": "trk-0001",
  "level": "D3",
  "model": "linear",
  "n_epochs": 4,
  "ra": 269.4,
  "dec": 4.7,
  "mu_arcsec_yr": 1.2,
  "pa_deg": 90,
  "catalog": "none|gaia-dr3",
  "confidence": 0.7,
  "caveats": ["residual-only", "3 epochs"],
  "nodes": [{"epoch": "...", "stage": "L1|residual", "ra": ..., "dec": ...}],
  "discovery_claim": false
}
```

## 3. API/UI

### API

```http
GET /api/tracks?target_id=barnard&fov=0.2
GET /api/tracks?ra=...&dec=...&fov=...
```

- 复用 `data_layer.build_dataset` + `cascade_layers`；
- 返回 `counts`（D0–D4）、`tracks`、`limits`、`disclaimer`；
- DB 不可用 503；不写 DB。

### UI

- `/cascade` 增加“轨迹层 / Tracks”tab，或新 `/tracks` 页；
- 顶部统计 D0–D4；
- track 卡片：level、model、n_epochs、RA/Dec、μ/PA、catalog、caveats；
- 点击 track 展开节点表；
- 点击节点可 `/api/identify`；
- 显著免责声明：“轨迹候选不是新天体；D5 才需人工/后续确认”。

## 5. 验收

### 合成

- 3 个注入源：1 stationary、1 linear mover、1 variable；
- 关联后：
  - stationary → D4（无星表）/D1（假星表）；
  - linear → D3；
  - variable → D4 + variable；
  - 不重复、不丢节点；
- 伪源/edge → D0。

### Barnard 真实

- 4 历元 cascade：L1 215、residual 241；
- `/api/tracks` 200，D0–D4 计数合理；
- 已知源（Gaia）尽可能 D1；
- 不出现“新行星/新恒星”正结论。

### 回归

- app 216 tests + 新测试；
- T1 45/0/1；
- T6 0 ERROR；
- Ego 轨迹页无 JS error。

## 6. 风险

| 风险 | 缓解 |
|---|---|
| 4 期太少，tracklet 歧义 | 保守门限；标 `insufficient` |
| residual 伪源 | quality/D0；5σ；不自动确认 |
| 6.15″ 混合 | 允许多候选/ambiguous |
| 跨波段流量不可比 | 只在同波段做变光 |
| 星表 partial | D1 只在 catalog_status=ok 时给 |
| 误写“新天体” | 固定 disclaimer + `discovery_claim=false` |
