### 0.1 从 01 提取的硬目标

1. 用户输入天区 RA/Dec（任意天区，不是写死几个）。
2. 显示该天区的**多期** SPHEREx 图像，像小视频。
3. 5 个指定天体必须能跑：Barnard's Star、Epsilon Indi B、WISE 0855、RW Aurigae、R Draconis。
4. 面向公众：非专业用户能看懂。

### 0.2 从 01 提取的加分目标

- 跟进新数据发布；102 波段/6 阵列/实时光谱；相加/相减；FOV 可调；Gaia/WISE 叠加；URL 嵌入；污染标记；Astropy/Aladin 借鉴。

### 0.3 从 03/04/05 提取的工程约束

- 取数不能依赖 TAP/SIA/DataLink 单点；静态切片 + S3 路径重建 + 422 覆盖探测是主通道。
- 单文件 65 MB，EPSF 不参与切片但占 ~97%；必须服务端 HDU 裁剪（只留 IMAGE/FLAGS/VARIANCE/ZODI + WCS/WAVE）。
- 像素 6.15″，单片 3.49°；覆盖半径用半对角线 2.47°，不是 1.745°。
- 5 目标数据现状：Barnard 4 期真实、Eps 8 期/361 天、WISE 8 期但仅 1 期 3σ、RW 1 个时刻、R Dra 3 期 1 天。
- 变星反例：RW Aur / R Dra 位置不动、亮度变；不能把“相减非零”当移动。
- 旧项目 HUELLA X 的三个坑：只支持预设天区、5 目标没数据、DataLink 单点——本项目必须逐条消掉。

## 2. MoveScope（产品主工具）

- **分支/目录**：`tool/app` / `系统/app/`
- **参考依据**：01（R1–R4、相加/相减、FOV、URL、污染标记）；03（HDU/FLAGS/像素）；04（5 目标/变星反例）；05（旧项目只支持 `?campo=` 的坑）
- **角色**：用户唯一入口：输入坐标 → 取多期切片 → 测量 → BIC/判定 → 公众解释/证伪条件。

### 2.1 目标期望

**必须（P0）**
1. 任意 RA/Dec/FOV 输入；FOV 0.02–3.0°；非法值 400（`INVALID_FOV`/`FOV_TOO_LARGE`）。
2. 本地覆盖内走 DB v1 真实历元；无覆盖 `NO_LOCAL_COVERAGE` + SIM；DB 挂 `DB_UNAVAILABLE`；取数失败 `FETCH_FAILED`，不得写成“基线不足”。
3. 5 官方目标预设结果不回归；自定义官方坐标与预设 5/5 一致（含 RW/R Dra 的 V）。
4. 多期播放/叠加/相减/轨迹 + 时间轴；≥2 期可播。
5. 响应含 `schema_version=1.0`、`data.mode/provenance/fallback_reason/real_epochs`、`result.class/readiness/readiness_scope`。
6. 无 500：sample 200、FOV 400、越界像素安全、target+冲突坐标 400、半坐标 400。
7. 质量标记累加（`SATURATED_SOURCE`/`FEW_EPOCHS`/`SHORT_BASELINE`/`TARGET_OUT_OF_FRAME`/`BLEND_*`/`IMPLAUSIBLE_PM`）；BIC 与历元列表在研究者模式可见。
8. 缓存键含 release/version、原子写、坏 NPZ 可恢复；RESULTS 有 LRU/字节上限。

**应该（P1）**
- URL `?target=&ra=&dec=&fov=` 可嵌入；复制链接复现。
- 公众话术 + 置信度 + 可证伪条件；三栏 UI 可读。
- 对 5 目标输出可解释的“为什么是 S/V/L/U”。

**量化验收**
- app 单测 **104 tests OK**（当前）。
- T1 的 C/D/E/F 组全过；`D.coord_matches_preset` 5/5。
- 热缓存 5 目标 1–3 s；T1 全量 49 s。
- 自定义 Barnard `real/4/L2/S`；RW/R Dra `hybrid/8/L2/V`。

### 2.2 非目标
- 不做 102 波段实时光谱（当前只输出波段标签）。
- 不做 M5/M6 完整轨道拟合；O 类仅候选。
- 不做盲搜索/track-before-detect；依赖目录/DB 候选。
- 不做 Gaia/WISE 图像叠加。

### 2.3 失败模式
- IRSA 挂 → 缓存/离线；无缓存 → `FETCH_FAILED`/UNAVAILABLE。
- 目标饱和 → S + 上限，不硬报 μ。
- 目标在图像外 → 跳过该期 + `TARGET_OUT_OF_FRAME`，不 500。
- 坐标歧义（WISE 1.6′）→ 0.05° 匹配 + 显式说明。
