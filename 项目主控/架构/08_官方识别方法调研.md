# 官方参考资料与识别方法调研

> 时间：2026-11-15
> 目的：查清 NASA/IRSA 官方推荐的识别方法，以及 Backyard Worlds/WiseView 等相关项目的做法，判断本项目应复用哪些、避开哪些。
> 结论先行：**官方与相关项目都没有“一张图识别所有星”的方法；主流做法是“源提取 + 多波段/多历元 + 图像相减 + 星表/历表比对 + 人工复核”。**

## 1. 官方 Source Discovery Tool 的方法

这是与本题最接近的官方方法。它的学习目标写得很明确：

> Search and download SPHEREx images；implement a simple image subtraction to find red sources；visualize images/catalogs；select sources interactively and extract spectra.

### 1.1 完整流程

```text
SIA/TAP 查 SPHEREx  spectral images
  → 取 D2/D4 等波段
  → 单位转换（MJy/sr → µJy，乘 solid angle pixel map）
  → sep 估计并减背景
  → 按 FLAGS 建坏像素掩膜（含 bit 21、坏标志）
  → reproject_exact 到共同网格
  → 图像相减（如 D2−D4）找红源
  → SExtractor 在单图/相减图上抽源
  → Firefly/bokeh 交互选源
  → 对选中源做多波段 aperture photometry
  → 生成光谱
```

### 1.2 关键细节

- **背景**：`sep.Background` 非参数背景。
- **掩膜**：官方示例只把 `FLAGS=2097152`（bit 21）、`2`、`0` 等视作可用；坏标志单独处理。
- **重投影**：`reproject_exact` 保通量；mask 用 `reproject_interp`。
- **源提取**：**SExtractor**；配置里带 `default.nnw`（神经网络 star/galaxy 分类权重）。
- **相减**：D2−D4 找红色源；不是“多历元相减找移动”。
- **测光**：孔径 `3/4/5 px`；用 `VARIANCE`/掩膜/坏标志；生成光谱。
- **无位置先验**：官方描述是 “without requiring positional priors”，即不依赖星表位置，直接从图像找显著源。
- **人工交互**：Firefly 看图像 + 表格；bokeh 选源。

> **重要**：Source Discovery Tool 是“找显著源 + 测光谱”，不是“识别所有星”，也不做恒星/行星身份确认。

### 1.3 可复用性

| 官方做法 | 本项目现状 | 建议 |
|---|---|---|
| `sep`/SExtractor 抽源 | 自写 matched filter + find_peaks + 质心/孔径 | 可保留；若要更接近官方，评估 SExtractor/`sep` 的许可证与依赖 |
| FLAGS/bit 21 掩膜 | 有 FLAGS 处理，但未完整照 Table 16 | 补齐 Table 16 的坏标志 |
| `reproject_exact` | C-P1A/P1B 尚未做共同网格 | C-P1B-2 必做 |
| 图像相减找红源 | 只有显示用 diff，无正式源提取 | 可作为“红源/瞬变”附加通道 |
| 多波段孔径测光 | 当前 SPHEREx 单波段/窄带，未做光谱 | 102 波段加分项再考虑 |
| 交互选源 | A/C 已有源列表；Firefly 未集成 | 现有 canvas 足够 |

## 2. 官方其他识别工具

### 2.1 MOST（Moving Object Search Tool）

- 输入：太阳系天体名称 / NAIF ID / MPC 一行根数 / 手动轨道根数。
- 功能：算轨道 → 预测位置 → 找 IRSA 中覆盖这些位置的 SPHEREx/WISE 影像。
- 用途：**已知**太阳系天体、precovery；也可用于“某候选是否已知”。
- **不是**未知行星发现工具；未知对象没有轨道根数，MOST 无法直接查。

### 2.2 Spectrophotometry Tool

- 在**用户给定位置**做 forced photometry/光谱；用 Tractor PSF 方法。
- 适合“我已经知道这颗星在哪，要它的光谱”，不适合盲找未知源。
- 与本项目 D 阶段“已知星表位置 + 强制测光”方向一致。

### 2.3 Data Explorer / Cutout Tool

- 看单张图、按坐标/尺寸切 cutout；用于人工核对。
- 不做自动分类。

### 2.4 Gaia DR3

- 已知恒星身份：`source_id`、PM、parallax、RUWE、颜色。
- 官方 Gaia 是**光学**，褐矮星/极红星常缺失；这正是 SPHEREx 的增量价值，也是“无 Gaia 对应”不能当“新星”的原因。

## 3. 相关项目的方法

### 3.1 Backyard Worlds: Planet 9 / WiseView

官方 About 页写得很直接：

- 用 WISE/unWISE **约 5 年基线**的 W1/W2 假彩色；
- 相减不同年份的图：快移动源像 “movers”，慢移动源像 “dipoles”；
- 变星、光学 ghost、blur 会产生假信号；
- **“人类眼睛”用于区分真实移动与 artifact**；
- WiseView 提供 blink、时间轴、FOV、对比度、Gaia overlay。

方法本质：

```text
多历元 WISE 图像
  → 相减/闪烁
  → 找 mover/dipole
  → 人工排除 artifact/变星
  → 星表/颜色/后续观测确认
```

这正是“移动天体发现”的经典方法，也解释了为什么“单图识别所有星”不是他们的目标。

### 3.2 NEOSSat

- 专用近地天体监测；方法仍是多帧检测/轨道确认；
- 对本项目主要是“近地天体监测”的叙事与 FITS 读取参考，不是直接复用代码。

## 4. 方法横向对比

| 方法 | 找什么 | 给身份吗 | 优点 | 缺点 | 适合本项目 |
|---|---|---|---|---|---|
| **Blink / 图像相减** | 移动/变光候选 | 否 | 直观、官方/Backyard Worlds 验证 | 伪源多、变星干扰 | ✅ 公众交互 |
| **SExtractor/sep 源提取** | 显著源 | 否（star/galaxy 弱先验） | 官方 Source Discovery 用法 | 6.15″ 混合、阈值依赖 | ✅ 源列表 |
| **多历元 BIC/显著性** | 运动/变光 | 否 | 可解释、小样本可用 | 需 ≥2–3 期 | ✅ 当前核心 |
| **Gaia/2MASS/WISE 交叉匹配** | 已知恒星 | ✅（known/ambiguous） | 身份可靠、PM 先验 | 星表不完备/极红星 | ✅ D 阶段 |
| **MOST/JPL/MPC** | 已知太阳系天体 | ✅（已知） | 轨道精确 | 未知对象无轨道 | ⏳ 未接 |
| **人工复核** | 排除 artifact | 辅助 | 官方验证有效 | 不可扩展 | ✅ 可选 |
| **ML 分类** | star/galaxy/artifact | 辅助 | 可扩展 | 标签/域偏移/黑箱 | 🟡 后置 |

## 5. 对本项目的直接建议

### 应该复用/对齐

1. **FLAGS Table 16**：补全坏标志/bit 21；当前只处理部分。
2. **共同网格重投影**：C-P1B-2 用 `reproject_exact` 或等价保通量方法。
3. **强制测光**：D 阶段对 Gaia 位置做 forced photometry，而不是完全依赖独立检测。
4. **图像相减**：作为“未知移动源/红源”的补充通道；但必须配合 artifact/变星排除。
5. **MOST/JPL/MPC**：用于排除已知太阳系天体；不要把它当“发现未知行星”。
6. **人工复核**：保留最终“候选→确认”的人工/后续观测环节。

### 不应承诺

- 不能“一张图识别所有星”；官方 Source Discovery 也不是。
- 不能“未匹配 Gaia = 新恒星”；Gaia 光学不完备，极红星会缺失。
- 不能“图像相减非零 = 移动”；RW Aur/R Dra 会误报。
- 不能“MOST 查不到 = 新行星”；MOST 只对已知轨道。

### 与当前 C/D 路线的关系

- 当前 C-P1B-1 的“S3 发现 + 单张 cutout + 检测”与官方 Source Discovery 的“SIA + 切片 + 源提取”方向一致；
- 缺的是官方那套 **共同网格重投影 + 强制测光 + 光谱**；这是 C-P1B-2；
- D 的 Gaia 比对方向与官方“Gaia overlay/identity”一致；
- 未知移动源还需要 MOST/JPL/MPC + 图像相减 + 人工复核。
