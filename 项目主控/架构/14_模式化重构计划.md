# 模式化重构计划：View 只选点，MoveScope 承载级联/轨迹

> 修正点：View 只负责“区域 + 时间 + 一次 handoff”；级联/残差、轨迹发现是 MoveScope 的显示模式，必须直接改变同一画布，而不是跳到独立页面。

---

## 0. 目标链路

```text
View：选 RA/Dec/FOV + 时间窗口
  → 只点一次“在 MoveScope 打开”
  → MoveScope 主界面：
       普通 | 级联/残差 | 轨迹
  → 同一画布随模式改变：标记/掩膜/残差/轨迹
  → 点击源/节点 → /api/identify
```

---

## 1. View 的改动

### 保留

- RA/Dec/FOV；
- 当前时相 + 分析窗口 ±N 天；
- URL `ra/dec/fov/t0/t1`；
- “在 MoveScope 打开”一个入口。

### 删除

- “进入级联 / 残差”按钮；
- “进入轨迹发现”按钮。

### 新 handoff

```text
http://127.0.0.1:8790/?ra=...&dec=...&fov=...&t0=...&t1=...&from=view
```

- 不传 `mode`；默认普通模式；
- 用户进入 MoveScope 后自己切模式；
- View 不再展示分析层/轨迹层任何内容。

---

## 2. MoveScope 的改动

### 2.1 URL / 时间窗口

主 app 接受：

```text
/?ra=&dec=&fov=&t0=&t1=&from=view&mode=browse|cascade|tracks
```

- `/api/analyze` 支持 `t0/t1`，只分析窗口内历元；
- 0 历元：200 + 空结果 + 说明，不 500；
- 1 历元：正常单期/SIM？不伪造运动；
- 无 `t0/t1`：旧行为不变。

### 2.2 模式栏

主界面增加：

```text
普通 | 级联/残差 | 轨迹
```

- 不跳页；
- 切换模式只改变同一 `#sky` 画布的叠加层和侧栏；
- 当前帧/时间轴/目标保持；
- `mode` 写入 URL，可深链。

### 2.3 普通模式

现有行为不变：

- 多期图像/播放/叠加/相减/轨迹；
- 目标分析；
- A 源点选。

### 2.4 级联/残差模式

数据：

- 调 `/api/cascade?target_id/ra/dec/fov/t0/t1`；
- 复用当前分析结果，不重新取图。

画布叠加：

- L1：实心点；
- masked：灰色/叉号；
- residual：空心/琥珀点；
- 图层开关：`L1 / masked / residual`；
- 当前历元只显示该历元的层；
- 可选“显示 residual 图”替换当前帧。

侧栏：

- 当前历元 L1/masked/residual 计数；
- 点击 residual 源 → 锁定 → `/api/identify`；
- 明确“residual 候选 ≠ 新天体”。

### 2.5 轨迹模式

数据：

- 调 `/api/tracks?...t0/t1`；
- 复用 cascade 结果。

画布叠加：

- 每条 track 的轨迹线；
- 当前帧节点高亮；
- 其他节点淡显；
- 点击 track 高亮，时间轴跳到该节点；
- 点击节点 → `/api/identify`；
- D0–D4 用颜色/线型区分。

侧栏：

- D0–D4 计数；
- 选中 track 的 model/n_epochs/μ/PA/caveats；
- 明确“轨迹候选 ≠ 新天体；D5 才确认”。

### 2.6 旧 `/cascade`、`/tracks` 页面

- 不再作为主入口；
- 保留为“详细表格/诊断页”；
- 从模式栏提供“详细表格”链接；
- 或者后续重定向到主 app `?mode=cascade|tracks`；
- 本轮先保留，避免删掉已有证据页。

## 4. 验收

### View

- 只有“在 MoveScope 打开”一个分析入口；
- 链接参数：`ra/dec/fov/t0/t1/from=view`；
- 无 JS error。

### MoveScope

- 进入后默认普通模式；
- 点“级联/残差”切换后，**URL 不跳页**，同一画布出现 L1/masked/residual 标记；
- 点“轨迹”后，同一画布出现轨迹线/节点；
- 当前帧/时间轴联动；
- 点击 residual/track 节点能 `/api/identify`；
- 页面无“新天体/新行星”正结论；
- `mode` 深链可复现。

### 回归

- app tests 234+；
- view smoke 40 项不回归；
- T1 45/0/1；
- T6 0 ERROR；
- DB 118 tests。

---

## 5. 风险

| 风险 | 缓解 |
|---|---|
| 主画布叠加复杂，破坏现有分析 | 先只读叠加，不改 `run_analysis`；模式切换不重跑取数 |
| 级联/tracks 数据量大 | 当前帧过滤；只画前 N 条；计数全量 |
| 时间窗口 0/1 期 | 明确空/insufficient |
| 旧 `/cascade` `/tracks` 深链 | 保留/重定向，保证不 404 |
| 模式切换后目标/时间丢失 | 单一 session state，URL 同步 |
