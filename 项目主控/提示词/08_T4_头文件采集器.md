## 工具定义

| 项 | 定义 |
|---|---|
| **名称** | 头文件采集器 / Header Harvester |
| **类型** | 数据采集工具（喂给数据库，不直接面向用户） |
| **一句话** | 用 S3 Range 只读每个 level2 文件的前 64 KB 头，落成 `.hdr` + manifest，再 `ingest headers` 填满数据库的 `date_obs/pixel_scale/crpix/psf/l2dqa/header_sha256`。 |
| **Owner** | 数据层 / 数据工程 |
| **输入** | S3 公开桶 `nasa-irsa-spherex`；DB 的 `target_epochs`（优先 74 条）或 `week_index.json`（全量） |
| **输出** | `app/data/header_cache/*.hdr`、`header_manifest.json`、DB 头字段与 Blob |
| **依赖** | `数据库工具/db/fitshdr.py`、`ingest headers`、`week_index.json`；stdlib only |
| **非目标** | 不下载整幅 65 MB FITS；不采像素；不改 app 管线；不做全量 14k 的强制要求（可分批） |
| **验收** | 74 条历元头 100%；`header_frames>0`；`date_obs` 非空；`target_epochs` 全链接；重跑幂等；`verify --deep` 通过 |

## 任务

### T1. 新建采集器

建议位置：`数据库工具/tools/harvest_headers.py`（数据层工具，放 DB 目录）。

CLI：

```bash
python3 harvest_headers.py \
  --source epochs \                # epochs | weeks | keys
  --out app/data/header_cache \
  --manifest app/data/header_manifest.json \
  --workers 8 --retries 3 --limit 0
```

参数：

- `--source epochs`：从 DB `target_epochs` 读 `(release, week, version, fits_key, obsid, detector)`；优先用 `fits_key` 直接 Range，不需要 S3 列举。
- `--source weeks`：读 `app/data/week_index.json`，对每周列 S3（`prefix={release}/level2/{week}/{version}/{det}/`），可加 `--detectors 1,2,3,4,5,6`。
- `--source keys --keys-file`：手工清单，便于补采。
- `--out`：`.hdr` 目录；默认 `app/data/header_cache`。
- `--manifest`：JSON 清单。
- `--workers`：并发（建议 8；S3 限速时降）。
- `--retries` / `--backoff`：429/5xx/超时重试。
- `--limit`：调试用。
- `--dry-run`：只列计划，不下载。
- `--resume`：已有 `.hdr` 且 sha256 匹配则跳过。
- `--no-ingest`：只采不 ingest；默认采完调用 `Ingestor.ingest_headers()`。

要求：

- 复用 `tools/find_epochs.py` 的 `_range`/`parse_hdus` 逻辑（可以重构为共享模块，但不要破坏 find_epochs）。
- Range 读取 `bytes=0-65535`（64 KB），不要下载整文件；SPHEREx IMAGE 头约 25,920 字节，64 KB 足够。
- `.hdr` 命名：优先可读名 `{release}_{week}_{obsid}_D{det}_{version}.hdr`；如果复用现有 SHA1 名，manifest 必须记录映射。`ingest_headers` 按内容解析，不依赖文件名。
- 原子写：临时文件 + `os.replace`；失败不留半截。
- 并发限速：信号量/队列；遇到 403/404 记录并继续；遇到 429 退避。
- 清单：每条约 `key, release, week, version, obsid, detector, url, file, sha256, bytes, status, fetched_at, error`。
- 采完调用 `ingest headers --dir <out>`（或直接 `Ingestor`），再 `relink_cutouts()` / `backfill_releases()`。
- 不要把 65 MB 整文件写进 Blob；只存头。
