## 任务

### T1. CLI 与报告

```bash
./run.sh --base-url http://127.0.0.1:8790 --db-url http://127.0.0.1:8797 \
         --report-dir report/2026-11-14 --offline
```

参数：

- `--base-url`（app，默认 8790）
- `--db-url`（默认 8797）
- `--view-url`（可选，默认 8830）
- `--report-dir`（默认 `report/<timestamp>`）
- `--offline`：对 app 子进程设置黑洞代理，验证缓存路径
- `--update-golden`：修复后更新黄金样本；必须人工确认
- `--only` / `--skip`：按用例组过滤
- `--no-start`：只测已运行服务；默认也不主动启动，健康检查失败则退出 2

报告 JSON 结构建议：

```json
{
  "schema_version": "1.0",
  "started_at": "...",
  "base_url": "...",
  "cases": [
    {"id":"R1.custom_barnard","group":"R1","severity":"P0","status":"FAIL",
     "expected":"mode=real, 4 epochs, L2, S",
     "actual":"mode=synthetic, 8 epochs",
     "evidence":"artifacts/R1.custom_barnard.json",
     "repro":"curl ..."}
  ],
  "summary": {"pass":0,"fail":7,"warn":2,"p0_fail":7}
}
```

`report.md`：按组表格 + 失败详情 + 复现命令 + 环境信息（端口、数据快照、git tag）。

### T2. 契约校验（A 组）

手写校验函数（不要新增依赖）：

- `Target`：7 条；字段 `id/name/ra/dec/official/expected/coord_unc_arcsec/truth`；`coord_unc_arcsec` 非空。
- `EpochRef`：`obsid/detector/release/week/version/mjd/date_obs/sep_deg/key/slice_url/provenance/frame_id`；`date_obs` 非空；`key` 非空；无重复 `(obsid,detector)`。
- `Coverage`：`radius_deg` 默认 2.47；`coverage_level` 以 `C` 开头；`baseline_days` 数值。
- `AnalysisResult`：`schema_version`、`data.mode`、`data.provenance`、`data.fallback_reason`（允许 null）、`data.real_epochs`（T2 后必须存在）、`result.class`、`result.readiness`、`result.readiness_scope`。
- 数据源：
  - app `/api/targets`；
  - DB `/api/v1/targets` 或 `/api/targets`；
  - view `data/targets.json`（若存在）。
- 失败即 P0（coord_unc 缺失为 P1）。

### T4. 5 目标 HTTP（C 组）

对 5 个目标 `POST /api/analyze`（`mode=auto, fov=0.25`）：

- HTTP 200；schema 合法；
- `mode` ∈ {real, hybrid, synthetic, sample, unavailable}；
- `provenance` 与 `mode` 自洽；
- `readiness`/`class` 与黄金样本一致（class 严格；readiness 严格）；
- μ 在黄金值 ±5% 或 ±1σ 内（若有误差）；
- 耗时 < 30 s；
- 任一 500 = P0；class 变化 = P0（因为这会改变产品结论）；耗时超限 = P1。

黄金样本初始值（来自 2026-11-14 快照）：

| barnard | real | 4 | L2 | S | 8033 |
| epsind_b | real | 8 | L3 | L | 4707 |
| wise0855 | real | 8 | L0 | U | null |
| rw_aur | hybrid | 8 | L2 | V | 49 |

### T5. 任意坐标（D 组，R1 核心）

四个用例：

1. **Barnard 精确坐标**（无 target_id）→ `mode=real`、4 期、L2、S；与预设一致（±1%）。
2. **RW Aur 坐标** → 至少 1 条真实历元（检查 `data.real_epochs >= 1`）；`mode` 为 real 或 hybrid；不得 `NO_LOCAL_COVERAGE`/0。
3. **未覆盖天区**（如 RA 0, Dec 0）→ `mode=synthetic`、`fallback_reason=NO_LOCAL_COVERAGE`、note 明确。
4. **DB 停机**（可选，`--db-down`）：
   - 预设 Barnard 仍 real 4（本地 JSON 回退）；
   - 自定义 Barnard → `DB_UNAVAILABLE`/SIM，不 500。
   - 实现方式：临时把 `SPHEREX_DB_URL` 指向黑洞端口（如 `http://127.0.0.1:9`），重启 app 子进程；不要杀用户的 DB。

任一不符 = P0。

### T6. 错误路径（E 组）

- `mode=sample` → 200 或 422，不是 500。
- `fov=-0.2` / `fov=0` / `fov=999` → 400，不是 500。
- `target_id=barnard` + `ra=10&dec=10` → 400 `TARGET_COORD_CONFLICT` 或明确 override；不得静默返回 Barnard。
- 非法 JSON / 缺字段 → 400，不是 500。
- 任一 500 = P1（sample/FOV 为 P0，因为 UI 直接暴露）。

### T7. 离线（F 组）

- 启动 app 子进程（隔离端口 8810），环境：
  ```bash
  HTTPS_PROXY=http://127.0.0.1:9
  HTTP_PROXY=http://127.0.0.1:9
  NO_PROXY=127.0.0.1,localhost
  ```
- 5 目标全部 200；结果与在线一致（mode/readiness/class 严格，μ ±5%）。
- 若任一目标需要网络（缓存缺失），报告 `FETCH_FAILED` 或 WARN，并指出缺哪个 NPZ；不要静默 SIM。
- 验收：5/5 成功（当前缓存已覆盖 5 目标）。

### T8. DB 一致性（G 组）

- `/api/v1/epochs?target_id=barnard` 与 `?ra=269.452077&dec=4.693365&fov=0.25`：4 条，逐字段一致。
- RW Aur：两入口 1 条。
- Eps/WISE/R Dra：两入口条数一致（10/10/3）。
- `date_obs` 全部非空；`key` 全部存在；无重复 `(obsid,detector)`。
- `coverage` 默认 2.47；`coverage_level` 以 `C` 开头。
- `header_frames` 与实际一致（不要求非 0，但不能虚报）。
- 任一不符 = P0（这是 T2 的前置）。

### T9. 视图工具（H 组，可选/手动）

- GET `view-url/?ra=269.452077&dec=4.693365&fov=0.5&target=barnard` 静态资源 200。
- 静态检查 `js/main.js`：
  - 不含 `../app/index.html`；
  - 不含 `method: 'HEAD'`；
  - 传给 MoveScope 的 URL 不含 5 位截断（可检查字符串 `toFixed(5)` 是否用于 `q`）。
- 若环境有 headless 浏览器（Playwright/Chrome/ego-browser），截图并检查选中目标；否则标记 `WARN: manual`，不阻塞 P0。
- 视图工具不进入提交硬门槛；失败为 P1/WARN。

### T10. 报告与退出码

- 每条用例写 `repro` 命令；失败时打印“期望 vs 实际”。
- 汇总：P0 fail >0 → exit 1；环境错误（服务不可达/端口错）→ exit 2；全过 → 0。
- 支持 `--update-golden` 只在全绿或人工确认后更新。
- 报告顶部写：git commit/tag（若无 git 写 `no-git`）、数据快照、服务端口、Python 版本。
