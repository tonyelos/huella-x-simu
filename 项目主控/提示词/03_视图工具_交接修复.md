## 任务

### T1. URL 参数：同时支持 search 与 hash

- 解析顺序：`location.search` 优先，其次 `location.hash`（保持向后兼容）。
- 支持参数：`ra`、`dec`、`fov`、`target`、`t`（MJD）。
- 示例：
  ```
  http://127.0.0.1:8830/?ra=269.452077&dec=4.693365&fov=0.5&target=barnard
  ```
  应选中 Barnard 天区，而不是默认 M101。
- 非法/缺参数：回退默认，不抛错；URL 更新时同时写回 search（可 `history.replaceState`），不要只写 hash。
- 验收：打开上面的 URL，页面 RA/Dec/FOV 与 Barnard 一致；复制链接能复现。

### T2. “在 MoveScope 打开”：路径、方法、精度

- 目标 URL：
  ```
  http://127.0.0.1:8790/?target=barnard&ra=269.452077&dec=4.693365&fov=0.5
  ```
  或（更稳）只传 `?target=barnard&fov=0.5`，让 MoveScope 用预设坐标。
- 坐标必须用**全精度**（至少 6 位小数），禁止 `toFixed(5)` 后再交给 MoveScope 做 `1e-6` 匹配。
- 探测用 **GET**，不要 HEAD；MoveScope 只实现 GET。若 GET 返回 200，直接 `window.open`；失败再复制链接并提示“请先启动 MoveScope（8790）”。
- 配置项：`MOVESCOPE_ORIGIN`（默认 `http://127.0.0.1:8790`），不要写死相对路径 `../app/index.html`。
- 如果当前选中天区正好匹配 7 个目标之一（角距 < 1″ 或坐标完全一致），带上 `target=<id>`；否则只传 `ra/dec/fov`，并明确提示“该天区当前会走自定义路径（SIM）”——在 T2 数据桥接完成前，这是诚实提示。
- 删除 toast “MoveScope 前端尚未落地（docs P3）”。
- 验收：点击按钮打开 8790，MoveScope 徽章为 `REAL`，目标名正确；不是 `SIM/自定义天区`。

### T3. targets 单一源

- 二选一：
  - A. 运行时 `fetch(${DB_ORIGIN}/api/targets)`，失败回退到 bundled 文件；
  - B. 构建时从 `app/data/targets.json` 或 DB 导出生成 `data/targets.json`，并在文件头写 `generated_by/generated_at/source`。
- 无论哪种，必须包含 `coord_unc_arcsec`，并修正 `rw_aur.truth`。
- 推荐 A + 回退：DB 的 `/api/targets` 已 CORS `*`，本地可用；DB 不在时仍能演示。
- 不允许手工维护第二份目标表；如果保留 bundled 文件，必须由脚本生成，不能手改。
- 验收：与 `app/data/targets.json` 逐字段一致（至少 id/ra/dec/official/expected/truth/coord_unc_arcsec）。

### T4. fields.json 可重建

- 修改 `tools/build_field_index.py`：
  - 加 `--source {db,export,headers}`，默认 `db`；
  - `db`：调用 `数据库工具` 的 `export fields` 或直接读 `数据库工具/var/exports/fields.json`；不要依赖 `app/data/header_cache`；
  - `--out data/fields.json`，默认不覆盖；加 `--force` 才覆盖；
  - 输出 `generated_by/source/generated_at/count`。
- 或者新增 `tools/export_fields.py`，保留旧脚本并标注 deprecated。
- 验收：删除/改名 `header_cache` 后仍能生成 5,857 行；与 DB `frames` 逐行一致；输出有来源与时间。

### T5. 覆盖口径

- 常量统一为 **2.47°**（半对角线）或从 DB `/api/coverage` 取；不要再用 1.745° 作为“有没有拍到”的默认。
- 统计拆成：
  - `frames`：探测器帧数；
  - `exposures`：不同 obsid；
  - `nights`：不同 UTC 日期；
  - `curated_epochs`：若读得到 DB `target_epochs`，显示真实候选历元数。
- 文案改为“本地命中 N 帧 / M 次曝光 / K 夜”，不要写“没有覆盖”当结果；RW Aur 至少显示 6 帧/1 夜。
- README 的“5,857 次曝光”改为“5,857 帧 / 5,544 次曝光”。
- 验收：RW Aur 不再显示 0；Barnard 显示 4 条 curated（若读 DB）或至少 10 帧/4 曝光；口径与 DB 一致。

### T6. 端口、品牌、错误提示

- 品牌：`SPHEREx 天区视图 · MoveScope`；删除 HUELLA_X。
- WebGL 初始化失败：提示“浏览器不支持 WebGL2”，不要误报“请启动 HTTP 服务”。
- 错误提示里的硬编码 8770 删除。
- README 更新运行端口、URL 契约、数据来源、已知限制。

### T7. 可选：静态自检

- 无测试框架时，至少加一个 `tools/smoke.py` 或 `node --check` 脚本，检查：
  - `index.html` 引用的 id 都存在；
  - `fields.json` 行数/键数；

  - `main.js` 不再出现 `../app/index.html` / `method: 'HEAD'` / `toFixed(5)` 传给 MoveScope。
