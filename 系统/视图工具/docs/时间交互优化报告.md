- 保留统一时间源 `commitTime(mjd, mode, {animate, source, silent, allowOutside})`；滑杆、UTC 输入、±快捷、键盘、播放、现在、预设/历元/命中行全部走它。

- 播放回退为连续时间：`mjd += dt × state.speed`；速度 `0.15× / 1× / 4×`（0.15 / 0.6 / 2.4 天/秒），默认 1×。
- 到 `mjdMax` 回绕 `mjdMin`；从末尾/now 起播先回 `mjdMin`；不再有观测序列步进、首尾特判或末尾停止 toast。
- 播放期间地球 `animate:false`，角度实时对应；手动改时间仍为 700ms 最短路径 ease-out tween；暂停后角度严格对应 `state.mjd`。
- 播放时钟模式为“数据时相”，页面标注“播放 = 连续时间”。

## 未完成 / 风险

1. **连续播放角度速度快**：4× 时约 2.4 天/秒，地球角速度很高；这是本次回退后的预期行为。
2. **默认/末尾按播放会先回 mjdMin**：旧行为；末次播放不自动停止，播放到末尾自动回绕。
3. **“现在”可超出本地索引**：时钟/地球/URL/窗口按当前时刻，滑杆在末端饱和。
4. **MoveScope 模式消费仍是 identify-owner**：View 只保留单 handoff，不接管普通/级联/轨迹模式。
5. **FOV 上限差异**：View 默认 3.5°，MoveScope 分析页限 3.0°；页面提示先调小，但链接按当前 FOV 发送。
6. **探活只证明服务应答**：`no-cors` GET 不证明分析健康。
