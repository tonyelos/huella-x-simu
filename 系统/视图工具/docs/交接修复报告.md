## 验收证据

### 1. 深链（T1）

命令：

```bash
cd 视图工具 && ./start.sh 8830
# 打开 http://127.0.0.1:8830/?ra=269.452077&dec=4.693365&fov=0.5&target=barnard
```

输出（页面实测）：

```text
ra=269.45  dec=4.69  fov=0.50
hits: 10 帧 · 5 曝光 · 3 夜
curated: 策展历元 4 · 数据库 epoch_catalog
preset active: barnard
url: ?ra=269.452077&dec=4.693365&fov=0.5&target=barnard&t=61316.5299
```

另测：

```text
?target=epsind_b        → RA 331.04 / Dec -56.78 / fov 0.50，27 帧 · 14 曝光 · 7 夜
?ra=120.5&dec=12.25&fov=0.4 → 2 帧 · 2 曝光 · 1 夜，ms-hint 显示 SIM 警告
?ra=abc&dec=&fov=999    → 回退默认，不抛错
#ra=269.452&dec=4.693&fov=0.3（旧 hash） → 仍生效
```

**前后对比**：旧的 `?ra=…` 被忽略（`readHash` 只读 hash），页面落在默认 210.80/54.35；新的 search 深链直达 269.45/4.69，并把 `target` 写进 URL。

### 2. MoveScope 交接（T2）

点击“在 MoveScope 打开”后新标签页 URL：

```text
http://127.0.0.1:8790/?target=barnard&ra=269.452077&dec=4.693365&fov=0.5
```

MoveScope 页面实测（`docs/evidence-movescope.png`）：

```text
徽章: REAL 真实
就绪度: L2 就绪度
来源: REAL · 4 期 · D1/D2/D3 · 真实 4/4 期
判定: S 静止（置信度 72%）
RA/Dec 输入: 269.452077 / 4.693365
```

**前后对比**：旧实现 `fetch('../app/index.html', {method:'HEAD'})` → 404/501，toast“MoveScope 前端尚未落地（docs P3）”；坐标 `toFixed(5)` → `sameAsPreset` 失败 → `custom → SIM`。
新实现：GET 探活 + 预设原值 + `target` → REAL。

未启动 MoveScope 时：按钮复制链接并提示“连不上 http://127.0.0.1:8790：先启动 MoveScope（app/server.py）”。

## 未完成/风险

1. **数据源在任务期间发生变化**：数据库 `frames` 从审计基线的 5,857 帧 / 15 周增长到 **5,893 帧 / 23 周**（头部采集器 run 35/36）。
   本次 `fields.json` 已按当前数据库重建，README/截图同步为 5,893。若主控的验收脚本仍写死 5,857，请以 `--check` 为准，或重跑采集后统一。
   提示词中的“5,857 行”属于旧快照，不是回归。
2. **自定义天区仍走 SIM**：取决于 MoveScope 的 T2 数据桥接（未完成）。视图侧已经明确提示，不伪装成真实。
3. **1″ 匹配是硬门限**：手输 `269.452/4.693`（少 4 位小数）会掉到 custom；预设芯片与深链不受影响。
4. MoveScope 探活是 `no-cors` 的 GET，只能证明“有服务应答”，不保证 `/api/analyze` 健康（19–29 s、依赖 IRSA）。
5. 覆盖判据是“中心距 ≤ 2.47°”，不是逐像素求交；对大倾角扫描带是保守估计。
6. 未处理 `app/` 侧问题（例如 MoveScope 显示“6 天基线”与说明里的 204 天不一致）——不在本工作包。

## 回滚方式

- 代码回滚：`git checkout -- 视图工具`（若已提交）；或从备份恢复整个目录。
- 数据回滚到审计快照（5,857 行）：`python3 tools/build_field_index.py --source export --force`
  （`数据库工具/var/exports/fields.json` 仍是 23:04 的 5,857 行版本）。
- 目标表回滚：`git checkout -- 视图工具/data/targets.json`，或重新运行 `tools/sync_targets.py`。
- 端口：停掉 `./start.sh` 的进程即可；本工具不写任何系统级配置。
