### 2. “在 MoveScope 打开”

点击后目标 URL（浏览器桩验证 alive 分支，实际捕获）：

```text
http://127.0.0.1:8790/?target=barnard&ra=269.452077&dec=4.693365&fov=0.5
```

- **路径/方法**：`MOVESCOPE_ORIGIN` 默认 `http://127.0.0.1:8790`，GET `/api/health`（`no-cors`），不再使用相对文件路径或 HEAD。
- **精度/目标**：命中预设（≤1″）时传 `target` + 预设原值；未命中只传自定义 `ra/dec/fov`，面板明确提示 SIM。
- **MoveScope REAL**：`app/web/app.js` 的 `sameAsPreset` 要求 `|Δ| < 1e-6`；上面的坐标就是预设原值，`target=barnard` 会被识别为预设，走 REAL 而不是 custom。
- 本轮把 MoveScope 复制到临时目录、在 **:8791** 启动（避免占用保留的 8790），直接打开上面的 URL 实测：

```text

readyBadge  L2 就绪度
sourceNote  REAL · 4 期 · D1/D2/D3 · 6 天基线 · 真实 4/4 期 · IRSA 静态切片实取 4/4 期 · 10.8s
RA/Dec      269.452077 / 4.693365
active      巴纳德星
```

`docs/evidence-movescope.png` 即本轮截图（REAL、L2、4 期、S、RA/Dec 全精度）。视图默认仍指向生产端口 8790；8790 关闭时的 GET 失败提示已在上一节实测。
- **未启动时**（8790 关闭）实测：

```text

```

## 未完成 / 风险

1. **自定义天区仍走 SIM**：取决于 MoveScope 的 T2 数据桥接；视图侧已明确提示，不伪装真实。
2. **1″ 匹配门限**：手输 `269.452 / 4.693`（少几位小数）会落到 custom；预设芯片、深链和“复制 JSON”不受影响。
3. **探活只证明服务应答**：`no-cors` 的 GET 不能验证 `/api/analyze` 的 IRSA 数据与渲染健康；真正的 REAL 分析仍以 MoveScope 结果为准。
4. **覆盖是中心距判据**：2.47° 是保守的“天区中心落在单片半对角线内”，不是逐像素求交；大倾角扫描带可能少算。
5. **旧 headers 源不可回归测试**：`header_cache` 已删除，只能验证其可读报错；可重建以 db/export 为准。
6. **MoveScope 实测端口**：本轮在临时副本 :8791 实测 REAL，避免占用约定保留的 8790；视图默认仍指向 8790，8790 关闭时的 GET 失败提示已实测。
7. **`window.MOVESCOPE_ORIGIN` 是前端全局配置**：静态页没有服务端环境变量；部署时在页面加载前覆盖，默认值仍是 8790。
