## 结论

View 职责已收窄为 **选区域 + 选时间 + 一次 handoff**：

- 删除两个独立分析按钮及其专用 URL 逻辑；页面只剩“复制 JSON / 复制链接 / 在 MoveScope 打开”三个动作，其中只有 **MoveScope 一个分析入口**。
- 保留分析时间窗口 ±N 天、`t0/t1` URL 读写、“窗口 = 分析层过滤范围”文案。
- “在 MoveScope 打开”只发：

```text
http://127.0.0.1:8790/?ra=<当前 RA>&dec=<当前 Dec>&fov=<当前 FOV>&t0=<MJD>&t1=<MJD>&from=view
```

- **不传 `mode`**（MoveScope 默认普通模式），**不传 `target`**；进入 MoveScope 后由主界面切换 **普通 / 级联-残差 / 轨迹**。
- 探活失败仍复制链接并 toast，不静默；旧深链（含 hash、无 `t0/t1`）不回归。

### 2. MoveScope handoff URL

点击“在 MoveScope 打开”后捕获：

```text
http://127.0.0.1:8790/?ra=269.452077&dec=4.693365&fov=0.5&t0=60970.0000&t1=61030.0000&from=view
```

参数解析：

```text
origin  http://127.0.0.1:8790
path    /
ra      269.452077
dec     4.693365
fov     0.5
t0      60970.0000
t1      61030.0000
from    view
mode    null
target  null
```

全精度坐标、窗口、来源标记齐全；没有 `mode`，也没有 `target`。

直接打开同一 URL（MoveScope :8790）实测：

```text
modeBadge   REAL 真实
readyBadge  L2 就绪度
RA/Dec/FOV  269.452077 / 4.693365 / 0.5
active      自定义天区
sourceNote  REAL · 4 期 · D1/D2/D3 · 取数 4/4 期 · 5.8s
```

MoveScope 自己会把 `target=custom` 追加到它的地址栏；View 发出的 URL 仍不含 `target`/`mode`，View 侧参数契约不被改动。

## 未完成 / 风险

1. **MoveScope 模式栏与 `t0/t1` 消费是 identify-owner 的工作**：当前 `origin/main` 的 MoveScope 主界面尚未实现“普通/级联/轨迹”同画布切换；View 已按契约只发一次 handoff，不接管分析层。
2. **旧诊断页**仍保留在 MoveScope 侧；View 不链接、不显示隐藏入口。
3. **FOV 上限差异**：View 默认浏览 FOV 3.5°，MoveScope 分析页限 3.0°；页面会提示先调小，但按任务要求仍发送当前全精度 FOV。
4. **播放中 URL 节流**：窗口显示约每 200 ms 更新，URL 在暂停/拖动时落盘；分享精确时刻请先暂停。
5. **探活只证明服务应答**：`no-cors` GET 不能证明 MoveScope 分析健康；真正模式叠加以 MoveScope 为准。
